## 🏙️ What is CricCity?

CricCity is a **procedural 3D data visualization system** where cricket player data transforms into a living, explorable city.

- 🏢 Every player becomes a building  
- 🌍 Countries become districts  
- 📊 Performance defines height & dominance  
- ⭐ The best player becomes the **Legend Tower**  
- 🎮 Explore the city in real-time (drag, zoom, click)  

> It feels like flying through a game map — except everything is real data.

---

## 🧠 How It Works

This is not static rendering. It’s a **data → geometry pipeline**:

```
Player Stats → Normalization → Score Mapping → 3D Structure → Interactive City
```

- Batters → Height based on runs  
- Bowlers → Height based on wickets  
- Separate normalization ensures fair visual scaling  
- Career length influences structure  
- Formats (TEST / ODI / T20I) dynamically reshape the city

## ⚠️ The Real Challenge

The hardest part wasn’t 3D.

It was **data**.

- ❌ No clean public cricket API  
- ❌ Cricbuzz not developer-friendly  
- ❌ ESPN data not structured for systems  

So everything was:

- 🛠️ Manually collected  
- 🧩 Custom structured  
- 🔄 Normalized into usable format  

> The system is scalable — the data is the bottleneck.
